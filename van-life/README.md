# 🚐 VanLife — Camper Van Rental Web App

A fully responsive React project that lets users explore, filter, and view detailed information about rental vans. Includes host-specific routes, interactive states, and modern UI inspired by the VanLife design concept.

---

## ⭐ Features

### 🔍 Public Features
- Browse all available camper vans  
- View detailed van information (price, description, type, image)  
- Filter vans by type: **Simple**, **Luxury**, **Rugged**  
- Fully responsive layout (mobile → desktop)  

### 🏠 Host Dashboard (UI Only)
- Dashboard overview  
- My listed vans  
- Reviews with rating breakdown  
- Income chart and transaction history  
- Host van detail pages with nested sections  
  - Details  
  - Pricing  
  - Photos
